# Bangalow Tennis Club — Championship 2026

A simple two-page website for the Bangalow Tennis Club Club Championship 2026.

## Pages
- **index.html** — home page: schedule, events, format, how weekly play works, the Spring Slam finals-day timetable, match rules, and contact/WhatsApp links.
- **results.html** — live results & standings for all 9 events (pool tables + finals). Every result cell is editable in the browser.

Both pages are self-contained (the club logo is embedded), so they can be opened locally or hosted anywhere static files are served (e.g. GitHub Pages).

## Publishing with GitHub Pages
1. Push this repo to GitHub.
2. In the repo: **Settings → Pages → Build and deployment → Deploy from a branch**, choose `main` / `root`.
3. Your site will be live at `https://bindaree21.github.io/BTC-Champs2026/`.

## Editing
- Results: open `results.html` in a browser, type into the highlighted cells, then save the file and commit.
- Schedule / content: edit the HTML directly.

## Events
